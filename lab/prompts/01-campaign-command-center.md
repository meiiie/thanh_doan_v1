# Imagegen prompt — Campaign command center

Use case taxonomy: `ui-mockup`  
Asset type: high-fidelity desktop web application screen, 16:10 landscape.

Create a high-fidelity desktop product UI mockup for a Vietnamese public-service workflow application named “Điều hành chiến dịch”. This screen is the campaign owner’s operational command center, not a marketing website.

REFERENCE ROLES:
- Reference 1 (HoLiLiHu admin): inherit its disciplined white 256px left sidebar, compact top bar, strong role-aware navigation, 8px rhythm, clean blue active state, thin borders and sober institutional tone. Do not copy wording, logo, or layout literally.
- Reference 2 (HoLiLiHu teacher): inherit readable Vietnamese hierarchy, list density and restrained primary blue action.
- Reference 3 (legacy campaign screenshot): understand the real domain and amount of Vietnamese operational data only. Explicitly do not copy its gray blocks, giant pie chart, emoji icons, cramped rows, excessive navigation, or old visual style.

CANVAS AND COMPOSITION:
- 16:10 desktop, approximately 1536×960 feeling, full application frame.
- White 256px left sidebar. Small simple abstract civic mark and product name “Điều hành chiến dịch” at top; no official trademark or copied emblem.
- Sidebar groups with clear line icons and exact short labels: “Tổng quan”; group “ĐIỀU HÀNH” containing “Hồ sơ đơn vị”, “Thẩm định”, “Kết quả & đối soát”; group “CẤU HÌNH” containing “Bảng tiêu chí”, “Phân công”, “Mốc thời gian”; group “QUẢN TRỊ” containing “Danh bạ & quyền”, “Nhật ký”. “Tổng quan” is active with a pale blue background and blue left indicator.
- Compact 64px top bar: campaign selector “TNTN Hè 2026”, current phase “Vòng 1 · còn 3 ngày”, notification, help, avatar. Avoid a large phase rail.
- Main header: eyebrow “CHIẾN DỊCH TNTN HÈ 2026”, title “Tổng quan điều hành”, concise helper text, one secondary button “Xuất báo cáo”.
- First content block is an attention queue with a strong heading “Cần xử lý”, four compact actionable rows, not four KPI cards: “3 đơn vị quá hạn”, “8 hồ sơ chờ phân công”, “6 hồ sơ im lặng trên 48 giờ”, “2 sai lệch điểm cần đối soát”. Each row has owner/status, a small count and a clear chevron or text link.
- Second row has one restrained horizontal workflow progress visualization at left and a compact “Hoạt động gần đây” list at right. Only one chart, no decorative pie/donut.
- Lower half is a readable operational table titled “Tiến độ đơn vị” with columns “Đơn vị”, “Trạng thái”, “Tiến độ”, “Phụ trách”, “Nút thắt”, “Cập nhật”. Show five realistic Vietnamese unit rows with varied states. Add compact search and filter controls above.

VISUAL SYSTEM:
- Background #F6F8FB, surface white, primary #0056D2, dark ink #0B1F33, border #DCE3EC, restrained success/warning/danger tints.
- Be Vietnam Pro or a similar highly legible Vietnamese sans-serif. Title 28–32px, body 15–16px.
- 8px spacing system; controls 44px; panels radius 12px; buttons radius 8px. Almost no shadows, thin borders, generous whitespace.
- Enterprise/civic, calm, precise and crafted. One visual hierarchy, not a mosaic of equal cards.

AVOID:
- gradients, glassmorphism, glow, illustrations, photos, 3D, fake browser chrome, watermark;
- oversized metrics, card soup, pill badges for every item, emoji, giant charts, duplicated statistics;
- unreadable microtext or placeholder lorem ipsum;
- blue used on large background areas; keep it as action and active-state color.

Success criterion: at a glance, the campaign owner can see what is blocked and where to act next.
